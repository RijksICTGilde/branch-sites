Elke branch in de repository van de demo is een eigen website. Je maakt een branch met de naam van je team, zet er HTML, CSS en afbeeldingen in en pusht. Binnen een paar minuten staat je website op /jouw-team/.

Wat heb je nodig

  • git, en liefst ook de GitHub CLI (gh).
  • Een token waarmee je naar de repository mag pushen. Die krijg je van de organisatie. Zet hem in de env var GH_TOKEN, niet in een bestand in de repository.

1. Token instellen en inloggen

 # De token die je van de organisatie kreeg export GH_TOKEN="github_pat_..." # gh gebruikt GH_TOKEN vanzelf; controleer dat het werkt gh auth status # Laat git dezelfde token gebruiken gh auth setup-git

2. Repository ophalen

 gh repo clone {{repo}} cd {{name}}

3. Eigen branch maken en erop overstappen

De naam van de branch wordt het adres van je website. Gebruik kleine letters, cijfers en streepjes, bijvoorbeeld team-zonnebloem.

 # Nieuwe branch maken en er meteen op overstappen git switch -c team-zonnebloem # Bestaat de branch al (bijvoorbeeld van een teamgenoot)? Dan alleen overstappen git switch team-zonnebloem

4. Website maken, committen en pushen

Zet een index.html in de root van de repository: dat is de startpagina. Gebruik relatieve paden, dus style.css of img/logo.png, en niet /style.css. Je website staat in een submap, en een pad met een / ervoor wijst naar de indexpagina.

 git add . git commit -m "Eerste versie van onze website" # De eerste keer: koppel je branch aan GitHub git push -u origin team-zonnebloem # Daarna is dit genoeg git push

Zonder de GitHub CLI

Heb je geen gh, haal de repository dan op met de token in de URL. Let op: de token komt dan in .git/config te staan. Deel die map dus niet.

 export GH_TOKEN="github_pat_..." git clone "https://x-access-token:${GH_TOKEN}@github.com/{{repo}}.git" cd {{name}}

Goed om te weten

  • Na een push duurt het een paar minuten voordat je wijziging zichtbaar is. Ververs daarna de pagina.
  • Verwijder je de branch op GitHub, dan verdwijnt ook je website.
  • Alleen bestanden die in git staan komen online. Er is geen server en geen build: wat je commit, is wat je ziet.
  • Alleen bestanden voor een website worden getoond: HTML, CSS, JavaScript, afbeeldingen, lettertypen, audio, video, PDF en CSV. Een .zip, .exe en dergelijke worden geblokkeerd.
